# Programming Decay Product Demo V3 Offline

This is the double-click version of the V3 prototype. It keeps the same visuals and interactions, but the page uses a normal local script instead of an ES module, so it can run from `file:///.../index.html` without a local server.

## Open

Double-click:

```text
index.html
```

or open this file directly in a browser:

```text

```

- Keep the `assets`, `app.js`, and `styles.css` files next to `index.html`.
- The local server files are still included as a fallback, but they are not required for the offline version.
