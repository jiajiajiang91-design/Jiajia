Entropy Atlas as the Evidence Layer of Programming Decay

Entropy Atlas 不是一张孤立的地图，而是 Programming Decay 治理系统中的「场地证据层」 — 把分散的客观地理数据与主观社区感知，自动化整合为可被后续算法（K-Means 选址、Pix2Pix 空间生成）调用的输入。

01
Problem · 问题
证据缺口
传统场地修复规划依赖专家直觉，缺乏可量化、可追溯的证据基础。客观污染数据与社区主观感知长期割裂。
02
Data · 数据采集
客观 + 主观双源
通过 Overpass API 抓取东伦敦约 1,000 处工业遗址点位（客观地理数据），同步调用 Google Places API 获取居民评论与情感评分（主观感知数据）。
03
Processing · 自动化处理
n8n 工作流编排
n8n 工作流编排两类数据的合并、去重、情感分析，输出结构化的多维数据集 — 把"数据采集 → 清洗 → 分析"流程自动化，减少手工整理成本。
04
Output · 可视化与下游接入
交互地图 + 算法接口
Leaflet.js 交互地图叠加客观分布与主观情绪两层信息，作为 Programming Decay 主系统的 K-Means 聚类选址输入 — 完成"场地证据 → 算法选址 → 策略生成"的闭环。
Entropy Atlas → K-Means Site Selection → Strategy OS → ML Generation → Hub Feedback
