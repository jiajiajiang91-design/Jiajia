Competitive Analysis — MemoryOS × mem0A side-by-side test of two cross-AI memory tools 竞品分析 — MemoryOS × mem0两个跨 AI 记忆工具的逐项实测

Hands-on test of mem0 / OpenMemory across three task flows: cross-AI recall, memory organisation, and user control. All three entry points stored memory in separate spaces — none combined into a shared context. Conclusion: cross-entry memory consistency is still unsolved. That doesn't prove MemoryOS is right, but it shows the position is worth working on. 亲手测 mem0 / OpenMemory，三条任务流：跨 AI 召回、记忆整理、用户控制权。三个入口各自存到各自的空间，跨入口记忆没有统一。结论：跨入口记忆一致性仍是个没被解决的问题。这不证明 MemoryOS 的方向就对，但说明这个位置值得做。

Programming Decay — Algorithmic Remediation硕士毕设 / 可追溯的场地修复链路 Programming Decay — 算法驱动的场地修复硕士毕设 / 可追溯的场地修复链路

My MArch thesis treats post-industrial contamination not as a one-time cleanup but as a design problem unfolding across three scales — from the planetary footprint of cement, through UK industrial corridors, down to a single site at Dagenham Dock. An algorithmic pipeline (GIS evidence → K-Means site selection → four remediation strategies → Pix2Pix spatial generation → Neural CA temporal evolution) makes each step traceable and explainable; the final spatial judgement remains with the designer. In product terms: turning scattered spatial evidence into a traceable, step-by-step decision workflow. 硕士毕设把后工业污染场地的修复重新定义为一个跨尺度的设计问题：从水泥产业的行星级污染足迹，经英国工业走廊，落到 Dagenham Dock 一块具体场地。一条算法链路（GIS 证据 → K-Means 选址 → 四种修复策略 → Pix2Pix 空间生成 → Neural CA 时间演化）让每一步治理过程可追溯、可解释；最终的空间判断仍由设计者完成。换成产品语言：把零散的空间证据，整理成一条可追溯、可逐步推进的决策流程。

From planetary cement metabolism down to a single 8×8 cell at Dagenham Dock, the thesis is laid out as one explorable interface. Three scales of evidence — planetary, national, site — feed into an algorithmic pipeline where each remediation step is traceable: why this site, why this strategy, why this spatial layout. The algorithm provides comparable, iterable design evidence; the final spatial judgement remains with the designer.

The Entropy Atlas — the n8n-orchestrated evidence layer of ~1,000 East-London post-industrial sites — is included inside this thesis as the site-evidence layer.

从全球水泥产业的行星级代谢，到 Dagenham Dock 上一格 8×8 网格的具体判断，整个毕设被整理成一个可逐步探索的界面。三个尺度的证据（行星、国家、场地）接入一条算法链路，让每一步治理过程可追溯：为什么选这个场地、为什么分配这种策略、为什么是这个空间布局。算法提供的是可比较、可迭代的设计证据；最终的空间判断仍由设计者完成。
