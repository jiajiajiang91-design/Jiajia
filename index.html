01.A
Shipped Product · MemoryOS V1 · v0.1.1 Windows Binary 已交付产品 · MemoryOS V1 · v0.1.1 Windows 安装包

One working memory, across every AI tool 一份工作记忆，贯穿每一个 AI 工具

Read case study ↗阅读 Case Study ↗

MemoryOS is a local-first desktop app that lets you carry a single working memory across ChatGPT, Claude, Cursor, Gemini and any other AI tool. The user keeps a folder of Markdown files; MemoryOS produces a standardised End Session Prompt the user pastes into the AI, then parses the AI's structured handoff back into updates the user reviews and saves.

No API integration. No clipboard scraping. AI suggests — user confirms. Built end-to-end as solo founder / PM / engineer; the case study unpacks the five product decisions and what would disprove them.

MemoryOS 是一款本地优先的桌面 app，让用户的一份工作记忆在 ChatGPT、Claude、Cursor、Gemini 之间复用。用户保留一个 Markdown 文件夹；MemoryOS 自动生成一份标准化结束对话指令，粘贴进 AI 后，再把 AI 返回的结构化 handoff 解析成更新项，用户勾选确认后写入本地。

不调用任何 AI 厂商的 API，也不监听剪贴板——AI 起草、用户拍板。从 PM、设计到工程，一个人端到端交付。Case Study 详细拆解 5 个核心产品决策，并写明哪种用户反馈会推翻当前判断。

Open standalone ↗独立打开 ↗

From planetary cement metabolism down to a single 8×8 cell at Dagenham Dock, the thesis is compressed into clickable product logic. Every scroll, every layer toggle, every inference call is one round of reasoning over the same contaminated ground. The black box is unfolded into explainable steps; the viewer is asked to drop the looking-at-a-project posture and enter an operating-a-system posture, where the decision is no longer the designer's alone but a result of human–machine collaboration.

The Entropy Atlas — the n8n-orchestrated evidence layer of ~1,000 East-London post-industrial sites — is included inside this demo as the site-evidence layer.

从跨国行业数据，到 Dagenham Dock 上一格 8×8 网格的微观决策，毕设被打包成一套可点击的决策后台。每一次滚动、每一次切换图层、每一次推理调用，都是对同一片场地的一次再判断。原本封闭的黑箱被翻译成可被解释的步骤；用户被引导从"看作品"的姿态，切换到"操作一个系统"的姿态——最终的决策不再属于设计师一个人，而是用户与算法协同的产物。

Entropy Atlas（熵图集）—— 由 n8n 自动化抓取的东伦敦约 1,000 处后工业场地证据层 —— 已作为证据数据源嵌入在该 Demo 内部。
