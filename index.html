◆Demo Interpretation解读 / a reading
— EN
Not a finished proposal — a decision machine you can operate.
From planetary cement metabolism down to a single 8×8 cell at Dagenham Dock, the thesis is compressed into clickable product logic. Every scroll, every layer toggle, every inference call is one round of reasoning over the same contaminated ground. The black box is unfolded into explainable steps; the viewer is asked to drop the looking-at-a-project posture and enter an operating-a-system posture, where the decision is no longer the designer's alone but a result of human–machine collaboration.
— 中文 / ZH
这不是一份已完成的提案，而是一台可被操作的决策机器。
从全球水泥代谢，到 Dagenham Dock 上的某一格 8×8 网格，毕设研究被压缩成可点击的产品逻辑。每一次滚动、每一次切换图层、每一次跑推理，都是对同一片污染场地的一次再判断。黑箱被翻译成可被解释的步骤；观者被邀请放下看作品的姿态，进入用系统的姿态——决策不再属于设计师一个人，而是人与机器协同的结果。
Evidence → Site → Strategy → Generation → Feedback　·　证据 → 选址 → 策略 → 生成 → 反馈

UCL 课设 — 2025▶ 查看交互 Demo →
◆Demo Interpretation解读 / a reading
— EN
A prequel that lets decay speak at the material scale.
Before Programming Decay turned into a city-scale decision system, this term-one prototype asks a smaller question: can decay itself be read as a design vocabulary? Pineapple skins, organic biomass and the seasonal cycle are treated as sensors and actuators; the facade stops being cladding and becomes a living interface that switches between HIBERNATION and RESPIRATION. The five views — Scan / Decode / Build / Twin / Atlas — walk you from a single material residue up to a full bio-cybernetic envelope.
— 中文 / ZH
让"衰变"先在材料尺度上说话。
在 Programming Decay 走向城市尺度的决策系统之前，这个第一学期的原型问了一个更小的问题：能否把"衰变"本身读作一种设计语言？菠萝皮、有机生物质与季节循环被当作传感器与执行器，立面不再是覆盖物，而是会在 HIBERNATION 与 RESPIRATION 之间切换的活体界面。五个视图（扫描 / 转译 / 构件 / 孪生 / 图集）把你从一片材料残留带到一整套生物—赛博的建筑表皮。
Residue → Sensor → Module → Facade → Twin　·　残料 → 信号 → 构件 → 立面 → 孪生
