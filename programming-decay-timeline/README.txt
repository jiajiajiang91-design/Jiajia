PROGRAMMING DECAY — Plate 02.5 — Barking Reach Timeline
======================================================

OFFLINE BUNDLE
--------------

This folder contains everything needed to run the interactive timeline plate
completely offline (no internet connection required after extraction).

Contents:
  Barking Reach Timeline.html   <- open this file
  assets/                       <- all archive images, demolition video, policy text

To use:
  1. Extract the entire ZIP to a folder anywhere on your computer.
     Keep the HTML file and the assets/ folder side-by-side — do not move them
     into different folders.
  2. Double-click "Barking Reach Timeline.html" to open it in your browser.

That's it. Fonts (Inter + IBM Plex Mono) are embedded inside the HTML file,
so the plate displays correctly without any network connection.
